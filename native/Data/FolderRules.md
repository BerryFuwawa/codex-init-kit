# Codex Folder Management Prompt V1.0

Configured Codex workspace root: <SELECTED_DRIVE>:\Codex

Use this root for Codex conversations, projects, temporary files,
shared resources, archives, documentation, and final deliverables.

Do not place active conversation work or project deliverables directly
in the Codex root. Use child folders.

Recommended locations:
- Conversations: conversation-specific work, notes, attachments, exports
- Projects: long-lived project source and working files
- OUT: final deliverables
- Temp: disposable intermediate files and scratch work
- Shared: reusable templates and assets
- Archive: completed or frozen work
- Config: workspace conventions and configuration
- Docs: workspace documentation

Naming guidance:
- Conversations\YYYYMMDD-topic-name
- Projects\project-name
- OUT\YYYYMMDD-project-or-task-name
- Temp\YYYYMMDD-short-purpose

At the beginning of each task, proactively classify the work,
choose the correct child folder, and create missing task folders when
needed. Keep newly created files in their correct locations and clean
up disposable files created by the current task when safe.

User-specified paths, repositories, and project locations take priority.
Do not move external repositories into this root.

Do not broadly reorganize historical files automatically.
Do not move, overwrite, or delete existing user files without explicit
authorization. If historical cleanup is requested, inspect first,
propose the mapping, then execute only the approved changes.

Before finalizing a task, verify that active work and final outputs are
stored in the correct folders and that the Codex root is not cluttered.
