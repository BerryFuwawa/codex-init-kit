# 原生初始化迁移：对等验收标准

本地开发，不发布。旧独立初始化流程为基线；不扩展为修改正在使用的 Codex。

| 功能 | 对等验收标准 |
| --- | --- |
| 状态／诊断 | 无写入；报告配置、代理、RTK、规则、运行时覆盖与官方包状态 |
| 命令入口／确认 | 支持一键初始化、仅基础重置、仅代理、指定／最近回滚、CUA检查修复、更新检查；未确认不改动 |
| 备份 | config、env、AGENTS、RTK文档／程序、指定旧CLI、PATH和两项用户覆盖在任何重建前完整保存；任一失败停止 |
| 基础配置 | 默认模型与旧脚本一致，配置键及可选多线程正确；不写已废弃字段 |
| 代理 | 开关、IP、端口验证；只改代理时不重建其他配置，保留可回滚原文 |
| RTK | 先检查已有组件；必要时从官方GitHub下载并校验SHA-256、ZIP完整解压；统计关闭与集成无交互；超时／非零／缺少实际产物判失败 |
| 全局规则／目录／子代理 | 原基础规则、RTK引用及选择的目录／子代理块各一份；标准目录仅补缺；项目规则与用户文件保留 |
| CUA | 官方包与当前算法匹配；目录／长度／逐文件SHA一致才通过；损坏时保留原目录；复制失败恢复原目录，未知算法／版本变化停止 |
| 进程 | 当前用户、会话、真实路径与启动时间核验；未授权不关闭，已自然退出跳过，身份改变／新进程／权限不足停止 |
| 结果／日志 | 真实成功、部分完成、失败／取消；错误非零，报告明确未完成步骤，不以进程退出0替代产物检查 |
| 精确回滚 | 恢复原始字节、原来不存在状态、注册表值与类型；兼容旧session.meta；不删除对话、记忆与项目目录 |
| 更新 | 固定仓库／版本／组件格式／SHA校验；只读发现、分阶段下载；原生工作进程替换与恢复，不启动PowerShell或改变执行策略；旧单CMD清单不能误作原生组件 |
| 防护／交付 | 隔离端到端及负例回归；服务运行和日志对照；真实高风险步骤单列未覆盖，不做全环境无拦截保证 |

生产实现只使用.NET／Win32及组件正式命令，不启用任何安全策略覆盖。测试通过注入环境、进程和下载依赖限制在临时目录。
