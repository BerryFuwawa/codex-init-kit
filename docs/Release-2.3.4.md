# v2.3.4 · 远控转发与自适应进度条

- 初始化时「工作区与网络」的代理 IP 下可选择「开启远控转发」。首次默认勾选，之后继承上次选择。也可在「连接与修复 → 连接状态」管理转发。开启后，本机访问 `chatgpt.com` 的系统域名解析指向内置转发服务，Codex 的「控制其他设备」可使用已保存的 HTTP／混合代理。
- 远控共用原有代理预设和自定义 IP／端口。开启时采用当前选中值，运行中保存新的代理后，新连接随之切换。
- 转发可在关闭工具后继续运行。初始化和连接状态页都提供「卸载远控转发服务」，会移除工具添加的 hosts 映射、卸载 Windows 服务并记住关闭状态。[设置与使用](WebSocket.md)
- 检查时，底部亮条会从轨道左端完整移动到右端。亮条长度和行程随窗口大小调整。
