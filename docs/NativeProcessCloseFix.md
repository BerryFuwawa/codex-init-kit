## 修复内容

关闭 ChatGPT／Codex 时，父进程退出可能使关联进程同时结束。旧实现随后继续读取已退出进程的 WMI 身份，可能显示“前置检查：找不到”，导致后续步骤全部跳过。

现在核对已绑定的进程实例：遇到 WMI 或 Windows 查询错误后，最多等待 500 毫秒确认该实例是否确实退出。确认退出后跳过，继续检查剩余进程；仍在运行、无法确认或权限不足时，仍停止初始化，并在日志写清阶段、进程名、PID 及错误码。进程身份变化不会被当成关闭成功。

用户报告的该次原始日志中，初始化结果 session 为 null，后续所有阶段均跳过，尚未进行配置重建。该日志没有完整异常栈；本轮用受控进程复现了相同报错和对应逻辑缺口。
