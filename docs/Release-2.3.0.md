# v2.3.0：全新界面，更好看，也更好用

[⬇️ 下载 Windows 版](https://github.com/BerryFuwawa/codex-init-kit/releases/download/v2.3.0/CodexInitKit.exe) · [查看使用说明](Desktop.md) · [文件校验](https://github.com/BerryFuwawa/codex-init-kit/releases/download/v2.3.0/SHA256SUMS.txt)

这次更新，重点让 Codex Init Kit 更好看、更好找，也更好操作。从选择配置到查看结果，整个过程都更清楚了。

## 🌙 换上全新的深色界面

采用柔和的雾夜蓝配色，菜单、按钮和弹窗统一焕新。页面切换和弹出提示更自然，常用功能也加上了更直观的图标。

## ⏳ 初始化进度，一目了然

不用再盯着一长串日志猜进度。现在可以直接看到正在做什么、哪些步骤已经完成、用了多长时间；需要排查问题时，再展开详细日志。

设置也按用途分好了：先选工作目录和代理，再选功能、CLI 和模型，确认后开始。执行中可以去看其他页面，结束后会自动回到结果页。

## 🧭 菜单更清楚，功能更好找

左侧分成「开始」「维护」「工具」三组，大分类和具体功能更容易分辨。初始化、浏览器修复、CLI 切换、备份回滚都有清楚的入口，当前在哪一页也更醒目。

## 🖱️ 滚动更顺滑，阅读不打断

长页面和日志滚动更连贯，更新检查结束后也会停留在原来的阅读位置。看日志时，上翻就暂停跟随，回到底部再继续显示最新内容。

## 🌐 代理端口，选软件就能填

继续支持 v2rayN、Karing、Clash 等常用软件的端口预设，也能沿用已有端口或自行填写。这次调整了端口旁的提示，预设入口更容易看懂，初始化和浏览器页面的设置保持同步。

## 🛡️ 火绒已确认此前检测为误报

11 月 13 日，火绒安全实验室回复：此前提交的 v2.2.13 文件经确认为误报，近期病毒库更新后可排除；相关 PowerShell 提示也会优化。

如果仍然遇到提示，请先更新火绒病毒库后再检查。

## 📥 怎样更新？

已有版本：打开工具，在「更新与下载」里检查更新。也可以直接下载本页的新版 EXE。

**更新工具本身不会自动执行初始化。** 如果选择完整初始化，工具会先备份，再重建配置；已有对话记录和项目文件会保留。

浏览器连接修复后，请按页面提示重启 Codex，再运行连接测试。

新版已完成本地构建和相关功能检查。[查看测试记录](Validation-2.3.0.md)
