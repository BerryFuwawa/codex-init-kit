## 界面与操作

- 原生 WPF 雾夜蓝界面，默认约 900 × 660。左侧按“开始／维护／工具”分组，页面入口缩进，配图标、连接线和当前页标记。
- 初始化配置分为工作区与网络、功能选择和模型设置，确认后显示阶段时间线、真实步骤进度、当前活动与耗时；详细日志按需展开。
- 连续滚轮保留速度，输入与日志区域统一平滑处理；更新检查结果局部刷新，保留阅读位置。
- 页面、按钮、下拉和弹窗使用短时非线性过渡，支持关闭系统动画；标题、分类、页签和常用操作配统一线性矢量图标。
- 端口预设使用信息图标与圆角提示标签，悬停显示说明；修复操作统一采用扳手图标。保留已有端口继承、预设填写和跨页同步。
- 保留初始化运行中切页、结束后返回结果页、中文／原始日志、底部跟随和暂停阅读状态，以及两类 CLI 的检测与手动选择。
- 回归和验证子进程使用隔离 CODEX_HOME，避免测试写入实际代理配置。
- 补充项目 MIT 许可和“关于与许可”入口，保留第三方规则许可。
