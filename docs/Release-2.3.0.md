# v2.3.0：银灰界面与阶段进度

状态：开发验收中，尚未发布可下载的 v2.3.0 EXE。v2.2.13 已撤回公开 Release，自动更新清单暂时保留 v2.2.12。

- 原生 WPF 银灰渐变界面，默认约 900 × 660；七项导航按开始、维护和工具分组。
- 初始化配置分为工作区与网络、功能选择和模型设置，确认后显示阶段时间线、真实步骤进度、当前活动与耗时；日志按需展开。
- 保留运行中切页、结束后返回结果页、中文／原始日志、底部跟随和暂停阅读状态。
- 页面、按钮、下拉与弹窗使用短时非线性过渡，支持关闭系统动画。
- 代理端口采用“阁下的代理端口：／填写框／预设／←常用软件预设端口”的顺序，保留配置继承和跨页同步。
- 后台回归显式使用隔离 CODEX_HOME，避免测试写入实际代理配置。EXE 的验证子进程共用隔离目录。
- 补充项目 MIT 许可，第三方许可保留，并提供关于与许可入口。
