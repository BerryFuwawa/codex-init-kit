# 复制日志与初始化兼容修复 · 本地 2.3.1.3

直接双击 CodexInitKit.exe，继续使用原有雾夜蓝界面。本文件可单独运行，保留之前的构建，本轮不上传 GitHub。

## 本次修复

- 复制日志或连接测试指令时，若剪贴板被其他程序占用，短暂重试后再复制。持续占用只在页面提示稍后重试，不弹错误窗。中文与原始日志仍复制当前显示的内容。
- 兼容本机 RTK 0.49.0 的已有文档：不再强制要求 RTK.md 与 AGENTS.md 同时出现在待创建列表。结合全局位置检查及已有内容复用文档，仍拒绝其他目录、缺失或空文档，不把不完整状态当成成功。
- 启动保护任务使用 UTF-16 声明与 UTF-16LE BOM 一致的 XML，修复任务接口的编码冲突。任务仍按当前用户、普通权限运行。
- 外部命令先读取原始字节，再识别 UTF-8、带 BOM 的 UTF-16，或回退到系统 OEM 编码，避免 Windows 任务命令的中文被替换成乱码。
- 日志将已知异常类型改为中文，并保留已有中文原因、路径及错误码；RTK／CODEX_HOME 等技术标识不再触发未知错误回退。WebSocket 中文名称不插入多余冒号。

## 权限

已迁移的初始化和维护操作主要处理当前用户的配置、缓存、备份及登录任务，默认不请求管理员权限。其他保留旧实现的维护入口仍沿用原有提权方式。权限不足仍需按具体日志处理，不会被当成成功。
