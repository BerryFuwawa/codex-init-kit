# v2.3.1：初始化更省心，原连接接着用

[下载 Windows EXE](https://github.com/BerryFuwawa/codex-init-kit/releases/download/v2.3.1/CodexInitKit.exe) · [SHA-256 校验](https://github.com/BerryFuwawa/codex-init-kit/releases/download/v2.3.1/SHA256SUMS.txt)

## 初始化按需更新，已有设置继续保留

初始化前先检查差异，只更新所选功能管理的内容。保留原有权限、自定义配置和未管理的全局规则；相同配置跳过写入，已是最新的组件跳过下载。

确认开始后，本次选择会固定下来。结束时显示实际结果，部分项目未完成可以单独重试，无需从头再来。完整初始化仍会先确认关闭正在运行的 Codex，请保存其他对话中的工作。

## 启动后，原资料和 Work 连接接着用

启动前识别当前实际使用的 Codex 资料，后续继续沿用，并带上本次代理和最新保存的 CLI 选择。重复初始化会保留已确认的原资料记录；无法可靠识别时，工具会给出操作提示并停止相关启动。

原连接异常时，可在“连接与修复”中使用“恢复原来的 Codex”。已有可靠记录时自动确定恢复目标；没有记录时，提示从平时使用的图标打开、确认原连接后继续，无需自己选择内部目录。[连接接续说明](DesktopProfile.md)

## 代理、日志和界面更顺手

- 同时继承已有代理的 IP 和端口；WebSocket 可沿用 HTTP 入口，也可单独填写代理。
- 浏览器、模型回复和 Dot 远程连接分开检查，保存或启动成功与实际连通分别显示。
- 初始化结果、后续检查和历史日志按操作保存；切页、上翻和中英文切换保留阅读位置。
- 结果完成后返回初始化页面；高缩放下操作按钮和长弹窗可以滚动查看。
- 保留雾夜蓝界面、清晰的矢量 Logo 和活动进度；初始化使用单文件原生后台，无需另下载辅助脚本。

## 验证与已知限制

166 项隔离回归、界面回归和本机模拟 WebSocket 转发检查通过。在同一台电脑的两次受控启动中，确认原资料、代理和 CLI 环境保持一致，原 Work 连接恢复在线。

完整实机初始化、所有界面按钮的完整操作流程，以及恢复后的 Dot 发送尚未实测；不将隔离通过或启动成功表述为全流程通过。[完整验证范围](Validation-2.3.1.md)

升级工具本身不会自动执行初始化。恢复连接前请处理未结束的远程请求；连接恢复后，旧请求可能继续执行。旧独立脚本保留原行为。发布 EXE 当前未代码签名，请从本仓库 Releases 下载并核对校验文件。
