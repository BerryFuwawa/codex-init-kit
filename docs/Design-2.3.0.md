# v2.3.0 界面与实现

## 信息架构

开始：概览、初始化。维护：连接与修复、CLI 管理、备份与回滚。工具：更新与下载、日志。

初始化配置按网络、功能和模型切换，之后统一确认。执行页以实际步骤时间线为主，详细日志按需展开；结果区保留具体失败原因及后续入口。

## 视觉与动作

背景 #191C23；卡片由 #4C5361 过渡至 #303641；主按钮由 #FAFCFF 过渡至 #B3C0D2；薄边线、12px 圆角卡片、8px 圆角控件。薄荷绿用于完成状态，红色用于切换提示或删除，未选择动作置灰。使用系统中文字体，不加载在线字体。

窗口默认 900 × 660，最小 800 × 540。代理端口保持 90px 填写框，预设紧凑显示；小窗口的侧栏和内容均可滚动。

页面约 220ms、弹窗约 240ms、按压 90ms／释放 140ms、下拉约 180ms。曲线使用 (0.22, 1, 0.36, 1)，重定向以当前值为起点。系统关闭动画后直接呈现终态。空闲页面没有常驻动画。

## 代码职责

| 文件 | 职责 |
| --- | --- |
| app/SilverTheme.cs | 色板、渐变与统一动画 |
| app/Controls.xaml | 按钮、输入、选择和进度条模板 |
| app/MainWindow.Pages.cs | 七项导航、页面布局和结果展示 |
| app/MainWindow.cs | 现有状态、配置、异步操作及日志连接 |
| app/InitializationProgress.cs | 根据后台事件维护阶段状态，不模拟任务速度 |
| app/Backend220.ps1 | 既有操作编排，输出带 stageId、state 和 detail 的阶段事件 |

现有 @@PROGRESS@@ 保留 step、total 和 title，补充阶段状态。@@INIT_RESULT@@ 的步骤增加 stageId，最终结果覆盖临时状态。子步骤只更新所属阶段的说明，不增加外层总数。失败或取消时停止活动状态，未执行项目标记跳过。日志协议和保存格式延续原有实现。
