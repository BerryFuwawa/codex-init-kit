# v2.3.0 界面与实现

## 信息架构

开始：概览、初始化。维护：连接与修复、CLI 管理、备份与回滚。工具：更新与下载、日志。

侧栏使用两级视觉层次：“开始／维护／工具”为不可点击的分类标题，采用较大加粗文字与分隔线；页面入口向右缩进，带线性图标和组内连接线。当前页面以浅蓝短标记、深蓝背景和加粗标签显示，所属分类标题同步强调。键盘焦点另有边框提示。

初始化配置按网络、功能和模型切换，之后统一确认。执行页以实际步骤时间线为主，详细日志按需展开；结果区保留具体失败原因及后续入口。

## 视觉与动作

雾夜蓝底色 #192330，卡片 #253343，侧栏 #1E2B3B；主按钮与选中态 #9DAFC4，按钮文字 #172535。正文 #ECEEF0，辅助文字 #AEB8C4，强调色 #AFBED0。分类卡片统一为 #2A3A4C，通过标题区分用途。输入、下拉、日志、进度、弹窗和窗口标题栏共用这一组蓝灰色阶；错误与警告保留单独的语义色。薄边线、12px 圆角卡片、8px 圆角控件。使用系统中文字体，不加载在线字体。

窗口默认 900 × 660，最小 800 × 540。代理端口保持 90px 填写框，预设紧凑显示；小窗口的侧栏和内容均可滚动。

页面约 220ms、弹窗约 240ms、按压 90ms／释放 140ms、下拉约 180ms。曲线使用 (0.22, 1, 0.36, 1)，重定向以当前值为起点。系统关闭动画后直接呈现终态。滚轮使用按帧计算的临界阻尼运动，连续输入保留速度，反向、拖动、键盘或页面切换会中断原目标；空闲时移除帧回调。鼠标进入日志和输入区域后仍使用相同的平滑处理，内层到底后可以继续滚动外层。更新检查结果只更新相关控件，保持整页位置。

图标采用内置线性矢量路径，覆盖侧栏、页面标题、分类、页签和常用按钮，无额外图标字体或网络资源依赖。

## 代码职责

| 文件 | 职责 |
| --- | --- |
| app/MorandiTheme.cs | 莫兰迪语义色板与统一动画 |
| app/Controls.xaml | 按钮、输入、选择和进度条模板 |
| app/MainWindow.Pages.cs | 七项导航、页面布局和结果展示 |
| app/MainWindow.cs | 现有状态、配置、异步操作及日志连接 |
| app/UiIcons.cs | 共用线性矢量图标 |
| app/SmoothScrollViewer.cs | 连续滚轮、嵌套区域与中断处理 |
| app/InitializationProgress.cs | 根据后台事件维护阶段状态，不模拟任务速度 |
| app/Backend220.ps1 | 既有操作编排，输出带 stageId、state 和 detail 的阶段事件 |

现有 @@PROGRESS@@ 保留 step、total 和 title，补充阶段状态。@@INIT_RESULT@@ 的步骤增加 stageId，最终结果覆盖临时状态。子步骤只更新所属阶段的说明，不增加外层总数。失败或取消时停止活动状态，未执行项目标记跳过。日志协议和保存格式延续原有实现。
