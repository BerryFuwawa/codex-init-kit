# 单文件原生桌面版

直接双击 **CodexInitKit.exe**，打开现有雾夜蓝图形界面。初始化按钮已接入原生后台，无需再打开独立 CLI。运行不需要旁置 DLL、配置文件、脚本、Python 或 PowerShell 7；使用 Windows 自带的 .NET Framework 4.8。

桌面代理保存到当前 Windows 用户环境，原生 CLI 同时使用 Codex 的 `.env`。保存后退出 Init Kit，继续使用原来的 Codex 图标。[持久网络配置与验收方式](PersistentNetwork.md)

## 保留的使用方式

- 功能分类、勾选状态、父子模型及思考强度、代理端口预设和当前 CLI 继承保持原样。
- 勾选的记忆、防止过度防御、笔记管理和命令行优先写入原来的位置。RTK 中文规则直接合入全局 AGENTS.md；项目规则和已有笔记不改变。
- 初始化前只读检测正在运行的应用，关闭须经本次明确确认。只处理确认过的进程实例，重新启动或身份变化时停止。
- 配置和原始文件先备份。取消或无法完成前置检查时不重建。新备份显示在现有备份列表，支持原生回滚、打开文件夹和确认后清理。
- 继续显示阶段进度、当前活动、耗时及中文日志；完成后返回初始化结果页，显示完成、部分完成或具体失败原因。

## 原生执行范围

初始化、前置检查、概览状态、代理保存、CUA 检查与修复、初始化回滚、备份清理、桌面版更新、官方独立 CLI 准备／更新、CLI 选择、启动保护安装、浏览器组件修复不经过旧初始化 CMD 或 PowerShell。

桌面更新仍由 winget 精确更新 Microsoft Store 官方包；程序核对包状态、安装渠道及组件签名，等待重启或组件不完整时暂停依赖修复。“当前软件源没有更新”保留为正常结果；版本探针访问被拒绝单独提示。普通网络失败保留手动更新说明。

独立 CLI 使用 OpenAI 官方完整软件包及发布元数据，检查下载 SHA-256、必需文件、OpenAI 签名及实际版本；Windows tar.exe 负责解压。沿用官方安装锁和 current／releases 布局，保留旧入口，不执行下载的 PowerShell 安装脚本。准备独立组件本身不切换 CLI、不注册登录任务。

启动保护在 Windows 登录时检查当前选择的 CLI，应用正在运行时跳过。CLI 类型由完整初始化应用。日志、备份、组件缓存和所选登录任务均由工具管理。

浏览器修复先备份现有运行时，再恢复当前官方版本文件。遇到无法识别的入口修改时停止并保留原文件。通过独立测试标签页验证实际网页读取。

其他尚未迁移的维护入口（例如旧保护卸载、部分诊断、浏览器恢复和桌面核心修复）继续保留原有实现；不能把整个应用描述成已完全移除 PowerShell。旧独立脚本保留，未改变其执行策略。

## 验证范围

桌面专用隔离回归覆盖选项映射、规则组合、记忆、进程授权、CLI 继承及恢复、失败后继续、组件更新、重复修复、代理关闭、回滚列表及结果页切换。共享原生核心回归覆盖备份、RTK、CUA、进程与更新器。

v2.3.3 通过 138 项桌面隔离回归、91 项共享核心回归和 71 项桌面综合检查。实际运行与未验证范围见[验证报告](Validation-2.3.3.md)。

## 源码构建

开发者执行：

```text
python tools/Build-Desktop.py 输出目录
```

构建使用系统 .NET 编译器，不执行 PowerShell 构建脚本。输出目录只需分发 CodexInitKit.exe。

实现依据：[OpenAI 官方安装器](https://releases.openai.com/codex/install.ps1)、[Windows 包状态](https://learn.microsoft.com/en-us/uwp/api/windows.applicationmodel.packagestatus)。
