# Codex Init Kit v2.2.13

> 本版本已撤回公开发布，保留源码、标签和历史记录。公开更新清单暂时回到 v2.2.12；后续界面升级见 v2.3.0 更新说明。

本项目完全开源，源码及构建脚本公开，初始化、维护和更新行为均可在仓库中核对。

- 代理端口改为「你的代理端口：」「端口填写框」「下拉菜单」同一行排列。预设涵盖 v2rayN、Karing、Clash Verge Rev、Clash／Mihomo、Hiddify 和 NekoRay，自定义位于最后。
- 启动时从已有 `.env` 读取端口并选中对应预设。未匹配的端口保留为自定义，没有配置时默认 v2rayN 新版 `10808`。
- 预设端口只读，自定义可编辑。自定义值、代理开关和页面切换保持同步，初始化及浏览器连接页使用相同控件。

## 验证与已知问题

端口读取、预设映射、自定义输入、跨页同步和紧凑布局已通过隔离专项测试。完整桌面回归中的后台脚本测试被本机火绒拦截，未全部通过。

火绒在本机对 v2.2.12 和 v2.2.13 开发构建出现过 `Backdoor/Meterpreter.el` 文件查杀记录；另有 PowerShell 系统加固提示。检测结论仍待火绒官方复核。
