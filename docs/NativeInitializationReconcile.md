# 本地初始化：按需修改与失败重试

本地候选基于 2.3.1.4，本地修复文件版 2.3.1.5，尚未发布。旧独立脚本和原生 CLI 的显式完整重置入口保留原行为。

## 使用方式

桌面初始化先检查所选设置，只合并工具负责的键。全局配置中的权限、插件、模型供应商及其他自定义项保留；代理文件保留其他变量和已有 NO_PROXY 排除项；全局 AGENTS.md 保留未管理的自定义内容。

配置、代理和规则一致时跳过写入。独立 CLI 先核对官方版本，最新或更高版本不下载、不降级。桌面版先查询商店更新列表。CUA 和浏览器入口完整且一致时跳过替换；启动保护程序与任务一致时跳过复制和注册；相同 WebSocket 设置不重复保存。

RTK 检查本机程序及统计关闭状态，缺失时才准备组件；规则直接内嵌 AGENTS.md，已有 RTK.md 和钩子保留。

## 管理员授权与结果窗口

勾选启动保护时，在开始初始化执行前一次性申请管理员权限；主窗口保持普通用户权限。取消 UAC 不开始初始化。仅重试浏览器等不涉及保护任务的项目时无需重复申请。单独安装启动保护同样先申请权限。

Windows 保存登录任务时可能省略默认运行级别，并把 SID 转成账户名；核验按实际账户、启动路径、参数、触发器与有效运行级别判断。注册后显式设置并核对当前用户的任务管理权限。

成功、部分完成、失败或取消授权后，工具恢复最小化的主窗口并显示结果，关闭结果弹窗后仍停留在初始化页面。

## 何时需要退出 Codex

配置与规则准备、健康检查、版本查询、WebSocket 启动准备不要求关闭当前对话。配置准备不代表当前运行中的所有会话立即采用新设置。

CUA 或浏览器运行时需要替换、CLI 模式实际改变，以及发现组件更新需要替换时，才要求退出。此时会说明影响；关闭整个桌面实例会中断该实例中的所有对话。当前实现不强行结束单个共享运行时来维持其他对话。

关闭确认提供“关闭并继续”“先处理无需关闭的项目”和“取消”。选择暂缓关闭后，无法安全执行的项目保留为未完成，其他项目继续。桌面或独立 CLI 更新在执行中才发现需要关闭时，先暂缓；点击重试会重新检查更新，再显示关闭确认。

## 仅重试未完成项

结果页显示“仅重试未完成项”。本次打开工具期间保留原始工作盘、代理、功能选择及已完成进度，不重跑其他顶层阶段。基础配置阶段内部重新检查，已经写好的文件跳过，仅补齐失败的部分。

本次关闭授权不会带到重试。新出现的进程或变化的进程实例需要重新确认。可继续从维护页面单独更新 CLI、修复启动保护或检查连接。

## 备份与回滚

首次实际变更前沿用完整配置备份；没有变化时不创建空备份。备份保存原始文件字节、原先不存在的状态，以及已记录的用户环境变量。回滚恢复备份时点的整份文件和记录的环境设置，会覆盖备份后对这些文件的编辑，请先核对目标时间。CUA、浏览器和 WebSocket 各自保留现有独立恢复方式。

设备登记数据库、installation_id、登录凭据、对话和项目数据不在写入与回滚目标内。不通过恢复旧设备来修复连接。

## 结果含义

- **配置已准备**：文件或启动设置已准备，尚不代表运行中的应用已采用。
- **隔离检查通过**：模拟进程、临时文件或独立探针通过，不代表真实 Dot 发送成功。
- **真实连接已验收**：需要对应客户端的真实列表、读取或发送结果。读取可用不能代替发送验收。

遇到无法安全定位的内联 TOML 管理项，会在写入前指出配置冲突，保留原文件。正式运行完整初始化、关闭应用、管理员任务注册及 Dot 发送仍需单独实机验收。

## 配置何时生效

结果页只列实际变更，并分别说明保存内容、生效方式、对其他对话的影响和核验程度。CLI 状态表示已保存的路径选择，不能代替运行实例核验；失败项重试保留先前变化记录。各项读取时点、配置覆盖与待验证项见[配置何时生效](ConfigurationEffects.md)。
