# v2.3.2：初始化回归简单

[下载 Windows EXE](https://github.com/BerryFuwawa/codex-init-kit/releases/download/v2.3.2/CodexInitKit.exe) · [SHA-256 校验](https://github.com/BerryFuwawa/codex-init-kit/releases/download/v2.3.2/SHA256SUMS.txt)

## 先完成配置，连接设置自己点一下

初始化专注于配置、组件和工作目录，不再自动恢复 Work 的电脑名称与控制授权，也不再要求工具读取桌面资料目录或身份文件。解决资料目录对工具不可见时，初始化被“当前 Codex 的资料暂时不可用”挡住的问题。

需要时，在 Codex/Work 中手动修改电脑名称、点击允许控制即可。连接页保留代理、浏览器、模型与远程线路检查，以及常规的修复并启动入口。

## 其他有效功能继续保留

- 所选配置按需更新，保留登录、用户资料、自定义配置与未管理规则；变更前备份。
- 失败项单独重试，日志和结果按操作保存；重复初始化跳过未变化内容。
- 保留代理 IP 与端口、独立 WS 线路、最新保存的 CLI 选择及官方组件准备。
- 关闭正在运行的 Codex 前仍需确认，并核验已授权的进程实例。
- 保留雾夜蓝界面、高缩放布局和日常维护功能。

## 验证与已知限制

132 项原生隔离回归、界面回归、模拟 WebSocket 转发和资源自检通过。覆盖资料目录不可见、旧观测记录损坏、无运行实例、首次和重复初始化、登录与桌面资料保持，以及进程授权与关闭确认。

故障机本轮离线，未执行该机的真实初始化或启动验收。本轮没有关闭或重启正在使用的 Codex，没有修改身份、凭据、连接记录或代理安全设置。官方桌面启动后的登录显示、Work 名称与允许控制需在实际使用时确认；这些状态由官方桌面管理。[验证范围](Validation-2.3.2.md)
