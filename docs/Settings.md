# 初始化选项（2.0.9）

可在初始化页面选择代理、功能和模型，确认页会展示本次实际选择。

## 代理开关

「初始化」页面的 HTTP 代理默认开启。第一行填写端口，默认 `10808`，按 V2RayN 常用设置预填；第二行填写 IP，留空使用 `127.0.0.1`。也可填 Clash 或其他代理服务提供的 HTTP／混合端口，以实际配置为准。

取消勾选后不需要填写端口。执行初始化或「维护恢复」中的「更新代理」时，将关闭本工具管理的 Codex 代理配置。修改开关本身不会立即改写 Codex 配置；需确认并执行操作。本工具自己的更新请求也遵循开关。

例如本机 V2RayN 可填端口 `10808`、IP 留空；软路由可填它提供的端口，例如 `7890`，IP 填路由器地址，例如 `192.168.1.1`。支持 IPv4 和 IPv6。IP 栏只填地址，不填 `http://` 或端口。代理服务需要已开启且允许当前电脑连接；此工具不负责启动代理服务。

## 可选功能

文件夹管理、CLI 启动保护与修复、CUA 检查与修复默认勾选；子代理多线程默认不勾选，可按需开启。取消勾选会跳过对应初始化步骤：

- 文件夹管理功能：创建标准工作目录、设置无项目任务目录和目录管理规则。
- 子代理多线程：写入子代理模型、并行数量和调用层级规则。
- CLI 启动保护与修复：检查／准备启动组件，安装登录维护任务。
- CUA 检查与修复：检查电脑操作组件，异常时修复。

基础配置仍会备份并重建。每次完整初始化还会先把全局 `$CODEX_HOME\AGENTS.md` 的完整原文件备份到本次会话的 `Backups\AGENTS.md`，然后从RTK 引用和基础工作规则重建全局文件。文件夹管理块和 Luna 子代理块只在对应选项勾选时写入；未勾选子代理时会将 `multi_agent` 设为 `false`，也不会写入 Luna 块或基础规则中的 `SUBAGENTS` 段落。旧的全局自定义内容只保存在备份中，不会保留在新的全局文件；项目目录中的 `AGENTS.md` 不受影响。已有 `Rollback.cmd` 可恢复本次会话备份。确认页会提示这是全局重置；初始化前保存工作，且仅需单项操作时使用「维护恢复」。

## 模型

默认选择「使用推荐模型」：父模型 `gpt-6.1-sol / medium`，子代理 `gpt-5.6-luna / max`。

选择「自定义父模型与子代理模型」后，可以填写两者的模型 ID，例如 `gpt-6.1-sol`。子代理功能关闭时不需要填写子代理模型。父模型思考强度沿用 `medium`，子代理沿用 `max`；请使用支持这些设置、且账号有权限使用的模型。工具检查输入格式，不验证模型服务端可用性。

执行前的确认页会列出实际选择的模型、代理状态和功能开关。下拉框与勾选框使用统一的深色样式，支持鼠标和键盘操作。

## 全局规则重建

初始化确认页会明确提示：本次操作会完整备份并重建当前全局 `CODEX_HOME\AGENTS.md`。新文件总是包含 RTK 引用和基础工作规则，只按选择追加文件夹管理块或 Luna 子代理块；原全局自定义内容不会自动带回。备份位于本次初始化会话的 `Backups\AGENTS.md`，由该会话已有的 `Rollback.cmd` 恢复。项目目录内的 `AGENTS.md` 不属于这次全局重置范围。
