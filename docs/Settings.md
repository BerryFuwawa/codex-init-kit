# 初始化选项（2.2.8）

可在初始化页面选择代理、功能和模型，确认页会展示本次实际选择。

## 代理开关

「初始化」页面的 HTTP 代理默认开启。第一行填写端口，默认 `10808`，按 V2RayN 常用设置预填；第二行填写 IP，留空使用 `127.0.0.1`。也可填 Clash 或其他代理服务提供的 HTTP／混合端口，以实际配置为准。

取消勾选后不需要填写端口。执行初始化或「维护恢复」中的「更新代理」时，将关闭本工具管理的 Codex 代理配置。修改开关本身不会立即改写 Codex 配置；需确认并执行操作。本工具自己的更新请求也遵循开关。

例如本机 V2RayN 可填端口 `10808`、IP 留空；软路由可填它提供的端口，例如 `7890`，IP 填路由器地址，例如 `192.168.1.1`。支持 IPv4 和 IPv6。IP 栏只填地址，不填 `http://` 或端口。代理服务需要已开启且允许当前电脑连接；此工具不负责启动代理服务。

## 可选功能

文件夹管理、防止过度防御、Codex 记忆、CLI 启动保护与修复、CUA 检查与修复，以及下方三个新增项目默认勾选；子代理多线程默认不勾选，可按需开启。取消勾选会跳过对应初始化步骤：

“子代理多线程”固定放在此功能列表的最后一项，位于“更新桌面版（含原生 CLI）”下方。

- 文件夹管理功能：创建标准工作目录、设置无项目任务目录和目录管理规则。
- 防止过度防御：将 HERO 中文精简规则和实现、防御、自主交付边界写入全局 `AGENTS.md`，默认勾选；[查看完整说明](AntiOverDefense.md)。
- 启用 Codex 记忆：默认开启本地记忆生成与使用；取消后关闭，已有记忆文件保留。设置在完整初始化时写入，不修改项目文件和对话记录。
- CLI 启动保护与修复：检查／准备启动组件，安装登录维护任务。
- CUA 检查与修复：检查电脑操作组件，异常时修复。
- 浏览器链接修复：使用同一代理设置准备浏览器入口补丁；关闭代理时恢复本工具管理的入口为直连，真实连接需重启后验证。
- 更新官方CLI：更新官方独立 CLI 组件，保留当前 CLI 模式，不单独安装登录维护任务。
- 更新桌面版（含原生CLI）：先通过 winget 更新当前官方 Microsoft Store 桌面包，原生 CLI 随应用更新。
- 子代理多线程：写入子代理模型、并行数量和调用层级规则。

功能列表下方的两个按钮选择初始化后使用的 CLI。默认“桌面版原生 CLI”，可改选“官方独立 CLI”；初始化确认页会展示选择。独立组件缺失时会按需准备，选择模式不要求安装启动保护。若原本使用独立 CLI，默认选择会将其切回桌面原生模式。

已安装启动保护时，登录自动维护和桌面工具的保护更新会保留明确选中的官方独立 CLI。若独立组件失效且桌面原生组件完整，自动维护仍可切回桌面原生模式。

执行顺序：退出检查 → 桌面更新 → 配置、目录及 CUA → 独立 CLI 更新 → 可选启动保护 → 应用并核验所选 CLI → 浏览器修复。开始前必须保存工作并退出 Codex；GUI 初始化不会强制结束当前任务。切换失败时尝试恢复初始化前的用户 CLI 路径设置，并显示未完成原因。桌面更新待完成或要求重启时暂停依赖修复和 CLI 切换。代理选项也与「浏览器连接」页双向同步；详见[浏览器故障处理](BrowserConnection.md)。

基础配置仍会备份并重建。每次完整初始化还会先把全局 `$CODEX_HOME\AGENTS.md` 的完整原文件备份到本次会话的 `Backups\AGENTS.md`，然后从RTK 引用和基础工作规则重建全局文件。文件夹管理、防止过度防御和 Luna 子代理块只在对应选项勾选时写入；未勾选子代理时会将 `multi_agent` 设为 `false`，也不会写入 Luna 块或基础规则中的 `SUBAGENTS` 段落。旧的全局自定义内容只保存在备份中，不会保留在新的全局文件；项目目录中的 `AGENTS.md` 不受影响。已有 `Rollback.cmd` 可恢复本次会话备份。确认页会提示这是全局重置；初始化前保存工作，且仅需单项操作时使用「维护恢复」。

## 模型

打开工具时，父模型和思考强度读取全局 `config.toml` 的对应设置。子代理优先读取该文件 `[agents]` 中的 `default_subagent_model` 和 `default_subagent_reasoning_effort`，未设置的项目再读取本工具全局 `AGENTS.md` 的托管子代理规则。各项都没有设置时分别使用 `gpt-6.1-sol / medium`。子代理仍默认关闭。

初始化时，子模型和强度会保存在 `[agents]` 默认设置；未勾选子代理时功能仍关闭且不写入子代理规则，勾选后另外写入本工具的子代理规则。模型或强度在内置列表中找不到时，保留现有值并标明尚未验证；配置读取失败时请先处理问题并重新打开工具。项目配置、命令行参数和单个对话的临时选择不属于全局默认值。

父模型和思考强度可直接通过下拉框更换；子代理模型仍使用下拉框，不提供任意文本输入。父模型与子模型各有加粗标题，模型 ID 与思考强度并排显示。下拉选项使用紧凑字体与行距，必要时支持平滑滚动。切换模型时，思考强度显示内置列表中的对应档位以及尚未验证的现有设置。子代理未勾选时，子模型与子思考强度置灰且不可选；勾选子代理多线程后即可设置，关闭再开启会保留本次选择。

列表按 2026-10-30 Codex 客户端返回的可见模型元数据预置；`gpt-5.5` 保留为旧版兼容选项，当前缓存未返回，不依赖本机缓存。点击「检查所选配置」，会核对所选模型和强度组合；当前已配置但不在列表中的值会保留并提示尚未验证。此检查不调用模型，不代表当前账号一定有调用权限。模型列表随本工具版本更新。

执行前的确认页会列出实际选择的模型、代理状态和功能开关。下拉框与勾选框使用统一的深色样式，支持鼠标和键盘操作。

## 全局规则重建

初始化确认页会明确提示：本次操作会完整备份并重建当前全局 `CODEX_HOME\AGENTS.md`。新文件总是包含 RTK 引用和基础工作规则，只按选择追加文件夹管理、防止过度防御或 Luna 子代理块；原全局自定义内容不会自动带回。备份位于本次初始化会话的 `Backups\AGENTS.md`，由该会话已有的 `Rollback.cmd` 恢复。项目目录内的 `AGENTS.md` 不属于这次全局重置范围。

## RTK 匿名统计与第 2/5 阶段卡住

v2.1.4 会在 RTK 集成前自动运行 `rtk telemetry disable` 关闭匿名统计，并关闭后台命令的标准输入，避免隐藏的 `Enable anonymous telemetry? [y/N]` 提示造成等待。关闭统计失败时会停止初始化，提示查看本次备份会话的 `rtk-telemetry.log`。

如果旧版任务已经卡住，先停止对应初始化任务，避免重复点击；在 PowerShell 终端运行 `rtk telemetry disable` 后，使用 v2.1.4 或更新版本重新初始化。新版不会自动终止已存在的旧版任务。

## 配置兼容警告

v2.1.5 可从「维护恢复」运行「检查配置」，再按需「清理已废弃配置」。清理仅针对 `features.code_mode_tool_description_first` 和 `features.guardianv2.thread_context` 的可靠布尔赋值，先备份原文件并生成 `Restore.ps1`；保留 Guardian 其他设置，不重置模型、代理或全局规则。

`session-flags` 提示来自会话参数时，文件中可能根本没有对应设置，删除文件内容不能消除该提示。配置检查会说明这个边界，不会把“文件中无需清理”当作“全部修复”。无需为了这两个警告执行完整初始化。详细步骤、扫描范围和恢复方法见 [配置兼容检查](ConfigCompatibility.md)。

## 记忆配置

“启用 Codex 记忆”位于防止过度防御之后，默认勾选。初始化将 `[features] memories`、`[memories] generate_memories` 和 `use_memories` 同步写为所选布尔值。不会清空 `CODEX_HOME\memories` 或改写记忆模型、整理周期和配额阈值。生成记忆可能使用 Codex 配额，实际生效取决于当前客户端和账户设置。[官方说明](https://learn.chatgpt.com/docs/customization/memories)

## GitHub 下载设置

在“更新”页设置并保存，默认官方优先、失败后串行尝试镜像。自定义前缀可留空，关闭后仅使用官方地址。设置与初始化中的 HTTP 代理相互独立；[查看完整说明](GitHubMirrors.md)。
