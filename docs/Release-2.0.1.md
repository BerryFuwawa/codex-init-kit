# Codex Init Kit 2.0.1

本次维护更新完善下载与更新配置，并同步使用说明。初始化流程与主要功能保持一致。

- 桌面版：`2.0.1`。
- 初始化脚本内部版本：`4.8.1`。
- 启动保护脚本内部版本：`5.2.1`。

下载 [CodexInitKit.exe](https://github.com/BerryFuwawa/codex-init-kit/releases/download/v2.0.1/CodexInitKit.exe) 即可使用，无需旁置脚本。使用旧版时，请手动下载替换；后续可通过应用内更新页面检查新版。

支持 Windows x64，使用系统 .NET Framework 4.8 和 Windows PowerShell 5.1。校验值见 `SHA256SUMS.txt`，详细操作及 CLI 自验方法见 [使用说明](https://github.com/BerryFuwawa/codex-init-kit/blob/main/docs/Desktop.md)。
