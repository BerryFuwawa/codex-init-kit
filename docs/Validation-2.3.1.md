## 实机启动与原连接接续

在官方桌面 **26.1111.2228.0** 上，经明确授权执行两次退出与启动：

1. 从此前使用的 Windows 官方应用入口打开，确认实际采用原有资料和旧 Work 环境。
2. 使用与界面共用的关闭、保存和启动代码再次打开，确认资料目录和旧 Work 环境保持一致。

两个目录参数均传入，子进程实际采用值一致。代理与 CLI 环境沿用原设置，代理配置文件未改变。两套既有执行器身份文件、登录及安装标识文件的元数据保持一致；没有复制、重置或修改身份。

登录状态和原对话可读取性保留。旧执行器重新连接远程服务，用户直接确认原电脑记录在线、新记录离线。两次实机退出与启动后，接续检查识别当前已在使用原资料，无需继续切换。

此项实测覆盖共用启动核心，没有逐个点击全部界面入口，也没有重新执行完整初始化。
