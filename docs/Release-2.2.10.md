# Codex Init Kit v2.2.10

- 修复初始化关闭 Codex 时的进程复核。已退出的进程直接跳过，仍在运行的进程按本次授权及实际身份处理。重新启动、身份无法核验、权限不足和等待超时分别显示原因。
- GitHub 请求按官方、自定义、内置十个镜像的顺序尝试。内置站点并行测速，下载或校验失败后换站。提交接口不可用时可从本项目 `main` 公开清单发现更新。[镜像设置](GitHubMirrors.md)
- 桌面初始化生成的全局 `AGENTS.md` 直接包含中文 RTK 正文，基础、文件夹和子代理提示词使用中文。防止过度防御改用 HERO 中文完整版，来源与许可保存在同目录的独立文件。[规则说明](AntiOverDefense.md)
- 恢复与回滚列表可以打开所选备份所在的文件夹，也可确认后清空回滚历史，保留当前及被引用的 CLI。工具更新完成后单独清理临时备份，文件被占用时保留并在后续启动时重试。

未选中条目时，“打开所在文件夹”置灰。删除回滚历史前会显示待删除数量并要求确认，涉及 CLI 缓存时请先退出 Codex。

Windows 桌面构建与回归覆盖初始化关闭确认、镜像顺序及校验失败换站、打开备份目录、批量删除与重试，以及应用更新与失败回滚。关闭进程和删除备份使用隔离测试。
