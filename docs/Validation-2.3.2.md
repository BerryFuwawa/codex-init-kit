## 问题定位

v2.3.1 在初始化预检中要求工具自身能读取 Codex 的逻辑资料目录。MSIX 的资料路径可能随 Windows 版本和进程包上下文呈现不同视图；Codex 能使用路径，并不保证外部工具能按同一路径读取它。Directory.Exists 的 false 也不能区分缺失与访问错误。

检查到官方桌面包同时包含旧版关闭虚拟化声明及新版仅排除 LocalAppData/OpenAI 的声明；Windows 10 与 Windows 11 的规则优先级不同。开发机为 Windows 10 LTSC 19044；该机读取结果不能替代故障机的环境。

2.3.2 取消了依赖这些读取结果的功能与拦截，无需推测、切换或创建资料目录即可完成初始化预检。

## 实机边界

故障机离线，本轮未进行其真实初始化、退出启动或 Work 控制实测。没有在开发机真实初始化或重启 Codex，没有操作现有身份、凭据、连接记录、代理或安全配置。

登录与桌面资料在隔离样本中确认保留；官方桌面启动后的实际显示和连接状态仍须在该机使用时验收。电脑名称与允许控制由用户在 Codex/Work 中手动设置。旧独立脚本保留既有行为。
