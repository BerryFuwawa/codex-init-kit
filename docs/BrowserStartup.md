# 从原图标启动 Codex

初始化或保存代理后，先保存工作并完全退出 Codex，再从原来的 Codex 图标打开。Init Kit 可以关闭，不需要专用启动脚本或常驻程序。

桌面代理保存到当前 Windows 用户环境，原生 CLI 同时使用 CODEX_HOME/.env。使用本地代理时，保持既有代理软件正常运行。配置对当前用户下其他遵循这些环境变量的程序也会生效。

浏览器组件缺失时使用“检查组件”和“修复组件”，恢复当前官方版本的文件；修复与真实网页读取分别验收。
