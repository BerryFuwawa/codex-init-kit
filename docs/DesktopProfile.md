# 用户资料与 Work 电脑设置

初始化按需备份并合并工具管理的配置，保留登录、对话、项目、已有记忆和未管理的自定义内容。工具不复制、重置或创建官方身份文件，也不删除 Work 连接记录。

## 电脑名称与允许控制

通过工具启动 Codex 后，如 Work 中显示的电脑名称需要调整，可直接在 Codex/Work 中修改。需要控制时，按官方界面提示点击允许控制。

工具不自动恢复这些状态，不读取身份文件或依据旧资料记录选择启动目录。正常初始化无需确认内部路径；资料目录对工具不可见也不会阻止配置初始化。

## 关闭与启动

检测到正在运行的 Codex 时，完整初始化和需要退出的修复操作会请求关闭确认。关闭会中断该桌面中的其他对话及 Work 连接，请先保存工作。没有运行实例时，常规启动无需额外确认。

启动仍使用官方注册入口，传入本次代理与最新保存的 CLI 选择。启动成功和远程连接实际建立分别报告。已有未结束的远程请求可能在连接恢复后继续执行，应先确认远端状态，避免重复发送。

完整初始化、代理设置、浏览器修复和身份设置分别有各自的范围。备份恢复方法见[桌面手册](Desktop.md)，本版验证边界见[验证报告](Validation-2.3.2.md)。
