# Codex Init Kit 2.0.11

- 父模型、子代理模型均用下拉框选择，预置 8 个官方 Codex 模型，不提供手动输入。
- 父模型、子代理各有思考强度下拉框，切换模型时只显示对应档位；确认页显示实际选择，初始化按选择写入。
- 子代理未勾选时也能提前选择模型和强度；是否启用仍由功能勾选决定。
- 增加「检查所选配置」，阻止非预设模型和不支持的强度组合。内置列表按 2026-10-04 官方客户端模型元数据预设，不依赖本机缓存；实际调用权限取决于账号。
- 修复 Windows 换行格式下子代理自定义设置可能未正确写入的问题。

已通过 CLI 自验、模型检查与自定义思考强度回归，并更新高清界面预览。验证未执行真实初始化。
