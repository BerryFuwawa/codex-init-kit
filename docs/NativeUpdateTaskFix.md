## CLI 更新

先检查本地官方组件的完整性、签名和实际版本，再查询官方发布信息：

- 已是最新：明确提示，无需下载、解压、替换或新增版本备份。
- 本地比当前发布渠道更新：保留本地版本，不降级。
- 有新版本：才下载并验证，再切换组件。
- 组件缺失或损坏：即使版本号相同，也会按需修复。
- 查询失败：保留可用组件，报告未能确认更新，不盲目重装。

只读版本核对和已准备组件的检查不要求退出 Codex；真正需要替换组件时继续要求先退出。

## 启动保护

这次现场检查确认：现有 CodexGuardAuto 任务归内置管理员组所有，当前用户只有读取权限，因此普通权限无法覆盖它。

现在优先按普通用户注册。遇到明确的访问拒绝后，才请求一次 Windows 管理员授权。独立辅助入口只更新固定的启动保护登录任务，不重复执行初始化、下载组件或改写 Codex 配置。授权后重新读取实际任务，核验程序、参数、用户和运行级别。

登录任务仍以当前用户、普通权限运行；给本用户保留该任务的管理权限。取消授权、使用不同管理员账户、其他系统错误或核验失败时，明确保留未完成结果。

已有完整独立 CLI 时，可以只在「CLI 管理 → 安装 / 修复保护」重试，不必再次完整初始化，也不需要为此关闭正在运行的 Codex。
