# v2.2.9

- **初始化功能分类**采用两列卡片，按工作与规则、权限与记忆、修复与连接、组件更新排列。子代理多线程单独位于底部。

- **按需笔记与文档管理**默认开启。Codex 可按需写 Markdown 任务笔记、补充长期文档并建立索引，保留可复用的成功和失败经验。
- **优先使用命令行**默认开启。Codex 在已有授权和权限范围内优先使用可靠的 CLI 或 PowerShell，并自行核验结果。
- **CLI 继承**默认沿用桌面原生或官方独立 CLI。确认页显示自动检测或手动选择。执行前复核自动模式，无法识别时由用户明确选择。
- **操作权限继承**默认开启。初始化保留全局审批、沙箱、文件与网络权限，确认页显示来源和摘要。支持多行配置及 granular 审批，原配置可从初始化备份恢复。
- **关闭应用确认**在开始初始化时检测正在运行的 ChatGPT／Codex。用户同意后先请求正常退出，再处理残留进程。取消返回确认页并保留选择。

两个规则可以分别关闭。初始化根据本次选择重建全局 `AGENTS.md`，原规则有完整备份，已有笔记、文档和索引会保留。具体行为见[初始化选项](Settings.md)。

验证使用隔离配置和模拟进程，覆盖权限继承、配置重建与回滚、关闭确认及取消流程。真实模型对话演练受本机连接错误 `10061` 阻断，仍待验证。浏览器连接需退出并重新启动 Codex 后另行验收。
